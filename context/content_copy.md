## UNIVERSAL BLOG ARTICLE LAYOUT

> **This layout applies identically to every article. Developers and writers must follow this spec for all 20 pieces.**

### Layout Structure

```
[URL Slug]
[Meta Title — ≤60 chars]
[Meta Description — ≤155 chars]
[Article Schema markup]
─────────────────────────────
HEADER ZONE
  - Site nav (sticky)
  - Article category tag  (e.g. "How-To Guide")
  - H1 Headline
  - Author name + date published + estimated read time
  - Hero image (1200×630px, WebP format)
─────────────────────────────
BODY ZONE (Two-column on desktop, single on mobile)
  LEFT / MAIN COLUMN (70% width):
    - Introduction paragraph (hook + problem statement, 80–120 words)
    - H2 section headings throughout body
    - H3 sub-sections where needed
    - Inline callout boxes for key stats or Skroll feature tie-ins
    - Conclusion paragraph with natural CTA reference
    - CTA Block: "Running an event in Sri Lanka? See how Skroll handles ticketing."
      → [Contact Us] button

  RIGHT / SIDEBAR COLUMN (30% width, sticky on scroll):
    - "In This Article" anchor-link table of contents
    - Skroll contact card:
        Headline: "Need a ticketing platform for your event?"
        CTA: Contact Us / WhatsApp button
    - Related Articles (3 links, auto-populated by tag)
─────────────────────────────
FOOTER ZONE
  - Tags (keyword chips)
  - Author bio (2 sentences)
  - Social share buttons (LinkedIn, WhatsApp, Facebook, X)
  - "Was this helpful?" thumbs up/down widget
  - Next/Previous article navigation
─────────────────────────────
TECHNICAL REQUIREMENTS (every article)
  - Article schema: type="Article", with datePublished, author, headline
  - Open Graph tags: og:title, og:description, og:image
  - Canonical URL set to primary slug
  - Internal links: minimum 3 per article (link to homepage, 1 feature page, 1 related article)
  - Image alt text: descriptive, includes primary keyword where natural
  - Reading level: Grade 8–10 (plain English, short sentences)
  - Word count: 1,200–2,000 words per article
  - Mobile-first layout: sidebar collapses to bottom on screens <768px
```
